[ Раздел 02 ]

Три подхода: по задаче и оборудованию

1

Аппаратная интеграция

через релейные входы/выходы и контроллеры, без сложного программного обеспечения (ПО). Подходит для простых задач и оборудования одного производителя

2

Программная интеграция

разные подсистемы объединяют через единое ПО, которое «понимает» протоколы каждого устройства. Удобно, когда оборудование от разных производителей

3

Программно-аппаратная интеграция

оптимальный вариант для серьёзных объектов — специализированные контроллеры плюс единое ПО с глубокой автоматизацией сценариев

Способ интеграции выбирают по задаче объекта и производителям оборудования

Способ интеграции выбирают по задаче объекта и производителям оборудования. Заготовка схемы: Принципиальная схема в три колонки: контроллеры с релейными связями / единое ПО над устройствами разных производителей / контроллеры плюс единое ПО.
