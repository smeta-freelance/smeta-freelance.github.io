[ Раздел 02 · Интеграция ]

Интеграцию реализуют тремя подходами — по сложности задачи и оборудованию

Аппаратная

Как

через релейные входы/выходы и контроллеры, без сложного программного обеспечения (ПО)

Когда

простые задачи и оборудование одного производителя

Программная

Как

разные подсистемы объединяют через единое ПО, которое «понимает» протоколы каждого устройства

Когда

оборудование от разных производителей

Программно-аппаратная

Как

специализированные контроллеры плюс единое ПО с глубокой автоматизацией сценариев

Когда

оптимальный вариант для серьёзных объектов

Способ интеграции выбирают по задаче объекта и производителям оборудования

Три подхода — ступенями по сложности задачи. Аппаратная: релейные входы/выходы и контроллеры без сложного ПО, для простых задач и оборудования одного производителя. Программная: единое ПО, которое «понимает» протоколы каждого устройства, — когда оборудование от разных производителей. Программно-аппаратная: специализированные контроллеры плюс единое ПО с глубокой автоматизацией сценариев — оптимальный вариант для серьёзных объектов. Вывод: способ интеграции выбирают по задаче объекта и производителям оборудования.
