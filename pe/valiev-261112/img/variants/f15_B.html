Зимнее удорожание: НДЗ аналогичного объекта, а без него — расчёт

По Методике №325/пр, п. 25: дополнительные затраты при производстве строительных и монтажных работ в зимнее время.

1

Объект не указан в таблице Приложения № 1 к Методике

2

Нормативный метод: НДЗ для аналогичного вида объекта капитального строительства

3

Нет НДЗ (или нет НДЗ по отдельным температурным зонам) — расчётный метод по главе III Методики, по образцу в Приложении 5

В соответствии с Методикой №325/пр, п. 25: дополнительные затраты в зимнее время для объекта, не указанного в таблице Приложения № 1, определяются нормативным методом с применением НДЗ для аналогичного вида объекта, а при его отсутствии и (или) при отсутствии НДЗ по отдельным температурным зонам — расчётным методом в соответствии с главой III Методики по образцу в Приложении 5.
