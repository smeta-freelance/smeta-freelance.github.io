Зимнее удорожание: НДЗ аналогичного объекта, а без него — расчётный метод

1

Объект не указан в таблице Приложения N 1 к Методике

2

Нормативным методом с применением НДЗ для аналогичного вида объекта капитального строительства

3

При отсутствии НДЗ (в том числе по отдельным температурным зонам) — расчётным методом по главе III Методики, по образцу в Приложении 5

В соответствии с Методикой №325/пр, п. 25: дополнительные затраты при производстве строительных работ и работ по монтажу оборудования в зимнее время.

Методика №325/пр, п. 25: для объекта не из таблицы Приложения N 1 — нормативный метод с НДЗ аналогичного объекта, иначе расчётный метод по главе III.
