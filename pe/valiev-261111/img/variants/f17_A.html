[ Ответ на вопрос 5 ]

Из нескольких частей — сложный объект

1

Если объект состоит из нескольких составных частей, каждая из которых имеет своё функциональное назначение,

2

то выберите вариант Сложный объект.

3

В экранной форме в разделе 1. Сведения об объекте капитального строительства добавляется пункт 1.8 Сведения о составных частях объекта.

Все данные для пояснительной записки к сметной документации можно найти в разделе №1 ПД «Пояснительная записка» (ГИПа).

Ответ на вопрос 5: несколько составных частей — выбрать «Сложный объект», добавляется пункт 1.8; данные — в разделе №1 ПД «Пояснительная записка».
