При подрядчике на УСН строка НДС в смете остаётся. НДС начисляют с полной цены работ. Строку «НДС 22%» не исключают, компенсацию не уменьшают. Ставку определяет акт, цену меняют только по соглашению. Главная мысль: при подрядчике на УСН строка НДС остаётся, меняется только концовка акта.
