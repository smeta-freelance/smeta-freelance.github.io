Нормативным методом с применением НДЗ

Дополнительные затраты при производстве строительных работ и работ по монтажу оборудования (монтажных работ) в зимнее время при подготовке сметной документации на строительство объекта капитального строительства, не указанного в таблице Приложении N 1 к Методике

Нормативный метод

с применением НДЗ для аналогичного вида объекта капитального строительства

при отсутствии НДЗ

Расчётный метод

в соответствии с положениями главы III Методики по образцу в Приложении 5

при отсутствии НДЗ по отдельным температурным зонам — тоже расчётный метод

Ответ по Методике №325/пр, п. 25: сначала нормативный метод с НДЗ, при отсутствии НДЗ — расчётный метод (глава III, Приложение 5).
